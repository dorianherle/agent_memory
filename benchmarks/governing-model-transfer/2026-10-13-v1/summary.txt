Private governing-model transfer test, 13 October 2026

Result: model transfer preserved prediction accuracy and reduced repeated
fitting work compared with replaying notes. A notebook with retained computed
results achieved the same predictions and work counts. This is not evidence
of an accuracy gain or a benefit unique to executable model transfer.

Method
- 384 exhaustive rule specifications; 336 distinct transition functions.
- Fixed integer relation: next_x = a*x + b*h(u) + c.
- Eight known expression forms, four choices for a and b, three choices for c.
- square(u) and square(abs(u)) are intentionally equivalent on this domain.
- Four handoffs: initial ambiguity, active discovery, transfer, source change.
- A fresh Python receiver process handles each condition at each handoff.
- Three identical initial observations, at most two active probes per active
  stage, and 24 fixed validation observations at the transfer stage.
- 110 fixed evaluation inputs per rule case, all outside the observation and
  probe grid but inside the stated input domain.
- All conditions use the same candidate language, learner, observations,
  test selector, query limits, and evaluator.
- The source revision change is announced equally to all conditions.
- No LLM calls. Hidden rules stay in the controller; worker requests contain
  observations and prior state. This is not an operating-system read barrier.

Findings
- Each condition completed 384/384 prediction tasks after discovery, transfer,
  and source change. Each such stage has 42,240 correct unseen predictions.
- All conditions withheld 34,560 of 42,240 initial predictions because rules
  disagreed. No incorrect prediction was returned at any stage.
- The candidate set fell from 384 to eight after initial observations.
  One distinguishing query per rule case then left one candidate in 288
  cases and two equivalent candidates in 96 cases.
- Reduction here means elimination of inconsistent candidates. The test does
  not discover a new expression language or establish unique physical laws.
- Fit relation evaluations across all stages: notes replay 834,816; cached
  notebook 424,704; executable model transfer 424,704.
- Total relation evaluations, including probe selection and prediction:
  notes replay 1,656,960; cached notebook 1,246,848; model transfer 1,246,848.
- All conditions made 768 active environment queries. Each received 12,288
  total observations, including initial and passive observations and queries.
- Observed total receiver times were about 4.06 s, 3.20 s, and 3.21 s.
  One run per condition, fixed order, one machine. No latency claim follows.
- Mean executable packet size fell from 1,327 bytes to 544 bytes at discovery.
  At transfer it was 547 bytes, versus 613 bytes of current raw observations.
  The cached notebook packet was 402 bytes. The first model packet was much
  larger than the initial observations. These are JSON bytes, not MDL scores.
- The full stage evidence archive is 607,366 bytes. It contains repeated
  snapshots of evidence. Raw evidence was retained when revisions changed.

Checks
- 71,808 interpreter outputs matched independent reference arithmetic.
- 3,072 condition comparisons matched observations, candidates, predictions.
- 1,152 out-of-domain inputs, 384 wrong-type inputs, 384 source mismatches,
  and 384 contradictory evidence cases were blocked.
- All 384 contradicted models were retained with their evidence.
- Without the source check, the old model would give 41,708 wrong outputs
  among 42,240 predictions after the constructed source change.
- Actual Agent Memory save, reopen, payload retrieval, and prediction passed
  for one sample model in a temporary store. Production code was not changed.
- Output checksums and protocol source hash passed verification.

Limits
This is a finite, noiseless, one-step mechanism test with a known model
language. It is not an agent benchmark, a general model-discovery result,
a test of full task paths, or a native token/cost measurement. Equivalent
candidate specifications are not independent trials. No statistical claim
about general tasks follows. Cached notes contain the same computational
knowledge; the observed savings come from preserving that computation.

Reproduction
From the repository root:
python3 scripts/test_governing_model_transfer.py freeze --output /tmp/governing-model-replay
python3 scripts/test_governing_model_transfer.py run --output /tmp/governing-model-replay
Use a new output directory. Freeze writes the source hash before the run.

Files
protocol.json: frozen settings and model language.
results.json: counts and diagnostic results.
receiver-records.json: complete requests' resulting states and predictions.
raw-evidence.json: observations grouped by task and source stage.
sha256.json: hashes of the original run files.
