## Provenance and reproducibility

These are **externally evaluated competition results**, not scores generated by the MemoryArena scripts in this repository. The organizing committee confirmed that the system's scores passed its review process. The public rankings are linked above.

This directory currently records the published scores and their sources. A reproducible submission archive—exact submitted code commit, configuration, model identifiers, prompts, evaluation commands, dependency lockfile, and raw evaluation outputs—has **not yet been added here**. Do not treat the current `main` branch as a verified exact copy of the competition submission without that evidence.

## Distinction from MemoryArena

The [MemoryArena results](../memoryarena/results_2026_10_14.json) are **author-run experiments** on a different benchmark. Their models, workloads, judges, baselines, and outcome metrics differ from AML. Neither result validates the other, and no cross-benchmark ranking is implied.
